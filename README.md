# Feeds

`feeds` — AI-first проект локального Telegram-дайджеста: система фиксирует новые публикации относительно собственных локальных cursor, систематизирует их через LLM, доставляет результат и только после полной подтверждённой доставки продвигает локальный прогресс.

## Текущий статус

Продуктовый, архитектурный и технический дизайн утверждён. Реализация начата
малыми вертикальными PR-срезами: созданы минимальный Python-каркас и публичные
контракты `ContentItem` и `CaptureBatch`. Остальные публичные контракты,
предметные модули, CI и поставка ещё не реализованы.

Наличие документа или плана не считается свидетельством реализации. Текущий
исполняемый контур проверяется командами:

```console
uv sync --group dev
uv run pytest
```
