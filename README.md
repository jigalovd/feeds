# Feeds

`feeds` — AI-first проект локального Telegram-дайджеста: система фиксирует новые публикации относительно собственных локальных cursor, систематизирует их через LLM, доставляет результат и только после полной подтверждённой доставки продвигает локальный прогресс.

## Текущий статус

Продуктовый, архитектурный и технический дизайн утверждён. Кодовая база приложения ещё не создана; наличие документа или плана не считается свидетельством реализации.
